# Площадки

Предлагать по рынкам пользователя. Особенности ниже записаны по реальным запускам. Сайты меняются: если поведение другое, доверять тому, что видно на странице.

## Общее

- **Браузер.** Откликаться в Chrome пользователя через Claude in Chrome: там его логины. Встроенный браузер подходит для чтения списков.
- **Свежесть.** Сортировать по дате, брать 3–7 дней.
- **Фейковая удалёнка.** «Удалёнка», но в тексте «5/2 в офисе», «только резиденты X», «аккредитованная IT-компания», «по ТК РФ» → это не удалёнка для иностранца.

## СНГ / Казахстан / Россия

- **hh.kz / hh.ru / hh.uz** — искать по названию: `text=NAME:("go developer" OR golang)`, `search_period=7`, `order_by=publication_time`. Формат задаётся через `work_format=REMOTE|HYBRID`, регион — через `area`: 40 = Казахстан, 160 = Алматы, 1 = Москва, 113 = Россия.
  - Отклик: «Откликнуться» → выбрать резюме трека → «Добавить сопроводительное» → «Откликнуться».
  - Успех — надпись «Вы откликнулись» или «Резюме доставлено».
  - Если hh просит сделать резюме «видимым всем работодателям» — это настройка аккаунта, спросить пользователя.
- **Habr Career** — «Откликнуться» отправляет отклик сразу. Письмо добавляется следом через «Дополнить отклик». Многие удалённые вакансии — только РФ.
- **getmatch** — в основном крупные компании РФ, удалёнка по РФ.
- **geekjob.ru**, **remocate.pro** — полный список после регистрации.
- **Telegram-каналы** — искать через tgstat.ru или telemetr.io. Ссылка в отчёте — на конкретный пост.

## Украина / Восточная Европа

- **DOU** — две формы.
  - Внутренняя: письмо в поле, файл резюме прикрепляет пользователь.
  - Внешняя: «Відгукнутися» ведёт на `dou.ua/goto/...` — это ATS компании (PeopleForce и др.). Заполнить имя, email, телефон, Telegram, ссылки и письмо. У некоторых форм лимит длины письма.
  - Часто встречается «Ukraine only» или требование украинского — отсеивать, если у пользователя этого нет.
- **Djinni** — анонимный профиль, компании пишут первыми. Отклик — короткое сообщение.

## Международные

- **LinkedIn Jobs** — AI-поиск может подставить «United States» и игнорировать локацию в URL. Локацию (страна / EMEA / Remote) выставлять в интерфейсе. Easy Apply часто спрашивает опыт по годам — брать из резюме.
- **Wellfound (AngelList)** — стартапы, профиль обязателен.
- **Welcome to the Jungle (Otta)**, **Himalayas**, **RemoteOK**, **We Work Remotely**, **Working Nomads**, **Jobgether**, **Arc.dev**, **Relocate.me** (релокация в Европу).
  - Проверять пометку «Worldwide» или список стран.
- **Нишевые:** golangprojects.com (Go), larajobs.com (Laravel), rustjobs.dev, python.org/jobs, Hacker News «Who is hiring» (раз в месяц).
- **hirify.me** — для агентов только официальный API/MCP. Каталог не парсить.

## Карьерные страницы компаний (ATS)

Greenhouse, Lever, Ashby, Workable, PeopleForce, Pinpoint, Breezy, SmartRecruiters.

- Claude заполняет текстовые поля из `contacts` и письмо.
- За пользователем: файл резюме, обязательная зарплата (если её нет в профиле), чекбоксы согласия, капча.

## Email-отклики

Если есть почтовый коннектор — создать черновик: тема, письмо, получатель из вакансии. Резюме прикрепляет и отправляет пользователь.

## Поиск новых площадок

Раз в неделю или по просьбе: веб-поиск вида `"<трек> remote jobs board"`, `"вакансии <трек> удалённо"`. Новую площадку проверить на реальных подходящих вакансиях и предложить добавить.
