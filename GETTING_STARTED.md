# Job Hunter — как начать

## 1. Что понадобится

| Что | Зачем |
|---|---|
| Аккаунт Claude (любой план, где есть Skills) | Скилл работает в claude.ai, десктоп-приложении и Claude Code |
| Chrome + расширение **Claude in Chrome** | Отклики идут в вашем браузере, под вашими логинами |
| Текущее резюме (PDF / DOCX / ссылка) или просто рассказ об опыте | Из него Claude соберёт резюме под нужные должности |
| Аккаунты на площадках (hh, Habr Career, DOU, LinkedIn…) | Можно завести по ходу — Claude подскажет, какие нужны |

## 2. Включить Skills

Settings → Capabilities → включить **Code execution and file creation** и **Skills**. В Team / Enterprise это включает владелец организации.

## 3. Установить скилл

```bash
git clone https://github.com/azhimov/job-hunter-skill
cd job-hunter-skill && zip -r job-hunter.zip job-hunter
```

Дальше в Claude: **Customize → Skills → «+» → Upload a skill →** `job-hunter.zip`. Проверь, что скилл включён.

**Claude Code:** `cp -r job-hunter ~/.claude/skills/`.

## 4. Первый запуск

Напиши в новом чате:

> **Хочу найти работу**

и приложи резюме. Дальше Claude ведёт по шагам.

| Этап | Что происходит | Что от тебя |
|---|---|---|
| 1. Должности | Спрашивает, кем хочешь работать, уровень, стек, формат, домены. Собирает 1–3 трека | Ответить своими словами, подтвердить таблицу треков |
| 2. Резюме | Задаёт недостающие вопросы (цифры, даты) и пишет резюме под каждый трек на RU/EN | Ответить, поправить, утвердить |
| 3. Данные для анкет | Телефон, email, Telegram, LinkedIn, GitHub, город, право на работу, английский, ожидания по зарплате, дата выхода | Ответить один раз |
| 4. Браузер | Проверяет Claude in Chrome. Если его нет — объясняет, как установить | Установить расширение, держать Chrome открытым |
| 5. Площадки | Предлагает площадки под твой рынок, открывает каждую | Войти самому, написать «готово» |
| 6. Поиск | Ищет вакансии, фильтрует, пишет письма, показывает список | Выбрать номера — «откликайся на 1, 3, 5» или «на все» |

Профиль сохраняется. В следующий раз хватит написать **«запусти поиск»**.

## 5. Команды

| Команда | Что будет |
|---|---|
| запусти поиск | Свежие вакансии → фильтры → список с письмами → отклики после «да» → отчёт |
| откликайся на 1, 3 / на все | Отклики по одному; засчитывается только при подтверждении площадки |
| перепиши резюме под … / добавь трек … | Новый трек и новое резюме |
| мне ответили: <текст> | Статус в истории + черновик ответа |
| пригласили на интервью в … | Документ подготовки к собеседованию |

## 6. Что Claude делает сам, а что оставляет тебе

**Сам (после твоего «да»):**
- заполняет формы контактами из профиля;
- вставляет письмо;
- отправляет отклик на площадках, где это одна кнопка.

**Оставляет тебе:**
- прикрепить файл резюме;
- чекбоксы согласия;
- капча;
- вход на площадки;
- отправка email-откликов;
- смена видимости резюме и других настроек аккаунта.

**Не делает никогда:**
- не спрашивает пароли и коды;
- не обходит капчу;
- не придумывает опыт;
- не откликается без подтверждения.

## 7. Если что-то не так

| Проблема | Что делать |
|---|---|
| Claude не видит браузер | Запусти Chrome, проверь, что расширение Claude in Chrome включено и вошло в тот же аккаунт |
| Капча | Пройди её сам и напиши «продолжай» |
| Много нерелевантного | «убери вакансии с …», «добавь стоп-слово …», «поменяй треки» |
| Письма не те | «короче», «без пересказа резюме», «добавь ссылку на GitHub» |

## Советы

- Держи резюме на всех площадках одинаковыми: компании, даты, должности.
- 10 точных откликов лучше 100 шаблонных.
- Отвечай рекрутерам в течение дня.
